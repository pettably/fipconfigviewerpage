Built-In Field Engineering Tools

More than just a viewer. Essential diagnostic, compliance, and calculation utilities designed specifically for fire alarm technicians on site.

AS 1851 Compliance

Test Sheet Exporter

Instantly export clean, structured testing spreadsheets and PDF checklists populated with live device addresses, loop numbers, and zone descriptions.

  • ✓ Pass / Fail / Defect sign-off columns
  • ✓ Filter by loop, node, or detector type
  • ✓ Ready for routine service audits
Smoke Sampling

Pipe Transit Stopwatch

Dedicated field stopwatch calibrated for measuring smoke transit times at the most remote sampling hole on VESDA Aspirating Smoke Detectors.

  • ✓ Real-time millisecond timing
  • ✓ Compare against Aspire design limit
  • ✓ One-tap recording into the test report
AS 1670.1 & 4428

Standby Battery Calculator

Calculate required power supply and Ampere-hour (Ah) battery capacity for 24-hour or 72-hour quiescent standby plus 30-minute full evacuation alarm.

  • ✓ Standard temperature de-rating factor
  • ✓ Aging safety margin calculation
  • ✓ Standalone VESDA & FIP battery calculations
Calculators

EOL Resistor Decoder

Interactive 4-band, 5-band, and 6-band color code decoder plus manufacturer reference tables for conventional zones, relays, and monitored lines.

  • ✓ Color band selector with instant Ohms value
  • ✓ Tolerance & temperature coefficient calculation
  • ✓ Reference values for Ampac, Vigilant, Simplex & Pertronic
Quality Assurance

Config Diff & Loop Audit

Compare two panel revisions side-by-side to highlight added devices, modified point descriptions, and altered logic equations before and after service.

  • ✓ Side-by-side point and equation diffing
  • ✓ Loop address limit & spare address audit
  • ✓ Unassigned zone text & duplicate detection
Diagnostic Port

Live Serial Terminal

Directly connect your laptop or Android field device to panel diagnostic and printer ports via USB-to-Serial converter for live event stream logging.

  • ✓ Windows & Android USB-serial support
  • ✓ Real-time event logging & text capture
  • ✓ Troubleshoot intermittent faults on site
